# 📄 Financial Document RAG

A Retrieval-Augmented Generation (RAG) application that lets you ask natural-language questions about financial reports (10-Ks, annual reports, etc.) and get grounded, citation-backed answers — no more manually scrolling through 200-page PDFs.

## ✨ Features

- 💬 **Conversational interface** — chat-style Q&A over financial documents, built with Streamlit's native chat components.
- 📚 **Grounded answers with citations** — every answer links back to the source document(s) and page number(s), expandable per document.
- ⚡ **Fast retrieval** — FAISS-based vector search over pre-embedded document chunks.
- 🧠 **LLM-powered responses** — answers generated by Llama 3.3 70B via Groq for low-latency inference.
- 📊 **Response metadata** — see how many documents were retrieved and how long the response took, for every answer.
- 💡 **Suggested questions** — guided starting points for first-time users.
- ⬇ **Downloadable conversation history** — export the full chat as Markdown.
- 🩺 **Live backend health check** — sidebar status indicator shows whether the API is reachable.
- 🎨 **Clean, minimal UI** — built entirely with native Streamlit components, no custom CSS.

| Layer            | Technology                          |
|-------------------|--------------------------------------|
| Frontend          | [Streamlit](https://streamlit.io)   |

## 🚀 Getting Started

### Prerequisites

- Python 3.10+
- A [Groq API key](https://console.groq.com/keys) (or your chosen LLM provider's key)

### 1. Clone the repository

```bash
git clone https://github.com/Dakshhhhh-ops/financial-doc-rag.git
cd financial-doc-rag
```

### 2. Set up the backend

```bash
cd backend
python -m venv venv
source venv/bin/activate      # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Create a `.env` file in `backend/`:

```env
GROQ_API_KEY=your_api_key_here
```

Run the backend:

```bash
uvicorn main:app --reload --port 8000
```

### 3. Set up the frontend

```bash
cd ../frontend
python -m venv venv
source venv/bin/activate      # On Windows: venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

The app will open at `http://localhost:8501`, and will connect to the backend at `http://127.0.0.1:8000/ask`.

## 🔌 API Contract

The frontend expects the backend to expose:

**`POST /ask`**

Request body:
```json
{
  "question": "What was Apple's revenue in 2025?"
}
```

Response body:
```json
{
  "answer": "Apple reported revenue of $X billion in fiscal year 2025...",
  "sources": [
    {
      "document": "Apple-2025-Annual-Report.pdf",
      "pages": [23, 24, 27]
    }
  ]
}
```
